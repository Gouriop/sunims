# LinkSpace &bull; Link Organiser &amp; Personal Dashboard

A lightweight, modern web app designed to organise web links, tools, and resources, paired with a dedicated personal profile space.

---

## 🌟 Key Features

### 1. 🔐 Corner Login Tab &amp; Editor Permissions
- **Corner Login Tab**: Located at the top-right corner (`Login to Edit`).
- **View-Only Mode (Logged Out)**: Public/team visitors can freely search, filter categories, sort, copy URLs, open links, and read person details without accidentally altering anything.
- **Editor Mode (Logged In)**:
  - Default password: `admin123`
  - Unlocks "Add New Link", card edit & delete buttons, favorite stars, and person details editing.
  - Includes a **Change Password** option right from the corner editor menu.
  - Smooth one-click **Logout** to switch back to View-Only mode.

### 2. 👤 Common Space for Person Details
- **Profile Card**: Displays name, role/title, team/department, email, phone number, and location.
- **Customizable Avatar**: Automatically generates modern gradient initials or displays any custom image URL.
- **Bio & Context**: Shared bio description of responsibilities or focus areas.
- **Key Profiles / Socials**: Fast one-click access to LinkedIn, GitHub, Portfolios, or any external links.
- **Shared Space Notes**: An editable notice board for working hours, quick team memos, or contact guidelines.
- **One-Click Edit**: Click **"Edit Info"** to update all person details instantly.

### 3. 🔗 Link Organiser Dashboard
- **Add / Edit / Delete Links**: Save any URL with a custom title, category, tags, notes, and favorite status.
- **Live Search**: Instant keyword search matching titles, URLs, tags, and notes simultaneously.
- **Category Tabs**: Filter easily between "All", "Starred", and custom categories (e.g., Work, Dev, Tools, Design).
- **Sort Options**: Sort by Newest, Oldest, Title (A-Z), Most Visited, or Favorites.
- **Grid & List Views**: Switch seamlessly between visual cards and a compact list view.
- **Quick Actions**:
  - **Open**: Direct link opening in a new tab + automatic visit tracking.
  - **Copy**: Instant clipboard copying with a toast notification.
  - **Favorite Star**: Star or unstar links with a single click.
  - **Auto Favicons**: Automatically fetches web icons for recognizable brands and websites.

### 4. 💾 Data & Portability
- **Auto Local Storage**: All links, visits, and profile details are automatically saved in the browser.
- **Export JSON**: Download a full backup of all your data at any time.
- **Import JSON**: Restore your data on any device or browser with one click.
- **Theme Support**: Seamless toggle between Dark Mode and Light Mode.
